# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

OpenShomer takes the security of autonomous AI systems and our own codebase seriously.

If you discover a security vulnerability within OpenShomer, please **do not** open a public GitHub issue. Instead, please report it privately:

1. **Email:** Send details to `security@openshomer.org` (or directly to the repository maintainers).
2. **Details to include:**
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if known)

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure.
