| Version | Focus | Core Deliverables |
|---|---|---|
| **v0.1 (MVP)** | Core Remediation Loop | Single-agent configs, prompt injection defenses, deterministic guardrails, Docker sandbox, evidence PRs |

| **v0.4** | RAG & Vector Security | Retrieval store access controls, context poisoning defenses |
| **v0.5** | Runtime Observability | Ingest live agent traces and runtime telemetry to close production feedback loops |
